# Security policy

This repository holds a static website. It contains no customer data, credentials or private keys.

If you find a security problem (an exposed file, a vulnerable script, a phishing look-alike of this site), please email **boundlesscad.design@gmail.com** with the subject "Security". Do not open a public issue for it. We reply within a few days.

If you received a message that claims to be from BoundlessCAD and asks for payment details, passwords or a wallet change, do not act on it — contact us through the address above first.
